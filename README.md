Code logbook for reproducing the analysis for morphine sudmex-rats project

## Summary

This repository contains the complete workflow and code for analyzing morphine effects in Sudmex rats, including behavioral assessments, MRI data analysis, and multivariate statistical approaches.

---

## Steps

[1. Environment installation](https://github.com/neuropsytox/Sudmex_morphine/blob/main/code/Env_configuration.md)   

[2. Morphine administration protocol](https://github.com/neuropsytox/Sudmex_morphine/blob/main/code/Morphine_protocol.ipynb)

[3. Behavioral metrics](https://github.com/neuropsytox/Sudmex_morphine/blob/main/code/Behavior_metrics.ipynb)

[4. MRI metrics](https://github.com/neuropsytox/Sudmex_morphine/blob/main/code/MRI_metrics.ipynb)

[5. Partial least square analysis](https://github.com/neuropsytox/Sudmex_morphine/blob/main/code/PLS.ipynb)

## Repository Structure

```
Sudmex_morphine/
├── Data/                    # Raw and processed data
│   ├── Behavior/           # Behavioral test data
│   ├── MRI/                # MRI imaging data
│   └── Datasets/           # Compiled datasets
├── Figures/                # Generated figures and visualizations
│   ├── Behavior/           # Behavioral analysis plots
│   ├── MRI/                # MRI analysis visualizations
│   ├── PLS/                # PLS analysis figures
│   └── Final_Figures/      # Publication-ready figures
├── Statistics/             # Statistical analysis outputs
│   ├── Behavior/           # Behavioral statistics
│   └── MRI/                # MRI statistics
├── code/                   # Analysis scripts and notebooks
│   └── utils/              # Helper functions and utilities
└── utils/                  # Environment configuration files
```

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/neuropsytox/Sudmex_morphine.git
   cd Sudmex_morphine
   ```

2. Follow the [Environment Installation](code/Env_configuration.md) guide to set up the required software environment.

3. Navigate through the analysis steps in order, starting with the morphine protocol documentation.
