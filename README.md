## Summary

This repository contains the complete workflow and code for analyzing morphine effects in rats, including behavioral assessments, MRI data analysis, and multivariate statistical approaches.

---

## Repository Structure

```
Sudmex_morphine/
├── Data/                    # Raw and processed data
│   ├── Behavior/           # Behavioral test data
│   ├── MRI/                # MRI imaging data
│   └── Datasets/           # Compiled datasets
├── Statistics/             # Statistical analysis outputs
│   ├── Behavior/           # Behavioral statistics
│   └── maps/                # MRI statistics
└── code/                   # Analysis scripts and notebooks             

```
