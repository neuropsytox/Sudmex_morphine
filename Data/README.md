# Data Directory

This directory contains all data files for the Sudmex morphine project.

## Structure

### Behavior/
Raw and processed behavioral data from various tests:
- Open Field Test (OFT)
- Elevated Plus Maze (EPM)
- Novel Object Recognition (NOR)
- Conditioned Place Preference (CPP)

### MRI/
Structural and functional MRI data:
- Anatomical scans
- Functional connectivity data
- Deformation-based morphometry (DBM) outputs
- Atlas files

### Datasets/
Compiled datasets combining multiple measures:
- Master dataset with all subjects
- Group-specific datasets
- Analysis-ready data files

## Data Formats

- CSV files for tabular data
- NIfTI (.nii, .nii.gz) for brain imaging data
- RData files for R-specific analyses
- Excel/XLSX files for original data

## Data Access

**Note**: Due to privacy and ethical considerations, raw data may not be publicly available. Contact the research team for data access requests.

## Data Organization Guidelines

1. Keep raw data separate from processed data
2. Use clear, descriptive file names
3. Include date stamps where appropriate (YYYYMMDD format)
4. Document any preprocessing steps
5. Maintain a data dictionary for variable definitions
